# Customer Segmentation Analysis

K-Means clustering on customer demographic and behavioral data to identify distinct segments for targeted marketing and product development.

## Overview

Customer segmentation groups a customer base by shared characteristics so a business can tailor marketing and product decisions to each group rather than treating all customers the same. This project applies K-Means clustering to a dataset covering demographics, income, policy preferences, and service interactions.

## Approach

1. Exploratory data analysis
2. Data preprocessing (missing value handling, encoding, standardization)
3. K-Means clustering
4. Cluster analysis and visualization

## Tech stack

Python, pandas, scikit-learn, matplotlib/seaborn

## Key findings

- Younger customers tend to have lower incomes and choose lower coverage; older customers have higher incomes and choose higher coverage.
- Older, higher-value clusters are strong candidates for premium, comprehensive product offers.
- Moderate-coverage customers are a distinct opportunity segment for targeted campaigns.
